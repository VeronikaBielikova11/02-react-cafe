# 02-react-cafe

A small, responsive café feedback widget built with React, TypeScript, and Vite for GoIT homework.

## Features

- Vote Good, Neutral, or Bad and see live totals.
- View the positive feedback percentage.
- Reset all responses when votes have been submitted.
- Responsive layout with component-scoped CSS modules.

## Getting started

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
